Lenskart India – Data Analytics Internship Project

About the Project

This project was completed as part of a Data Analytics Internship. The project focuses on analyzing Lenskart India sales data using Python, SQL, Power BI, statistics, and machine learning techniques.

Dataset

The dataset contains 150,000 sales records and was analyzed to understand sales performance, product categories, sales channels, store types, states, payment modes, and customer characteristics.

Data Preparation

- Checked missing values and duplicate records
- Converted order dates into proper date format
- Created year, month, and month name features
- Created a data dictionary
- Performed outlier analysis using the IQR method
- Prepared a cleaned dataset for further analysis

Task 1 – Exploratory Data Analysis

Tools: Python, Pandas, Matplotlib, Seaborn

Key activities:

- Dataset exploration
- Data cleaning
- Descriptive statistics
- Category and state analysis
- Sales trend analysis
- Correlation analysis
- Outlier detection
- Data visualization

Task 2 – SQL & Data Extraction

Tool: SQLite

Key activities:

- Created a sales database
- Imported the cleaned dataset
- Used SELECT, WHERE, ORDER BY and LIMIT
- Used GROUP BY, HAVING and aggregate functions
- Performed subquery analysis
- Used window functions
- Connected SQL with Python using Pandas

Task 3 – Data Visualization & Dashboarding

Tool: Microsoft Power BI

The dashboard includes:

- Total Sales KPI
- Monthly Sales Trend

- Sales by State

- Sales Channel filter
- Product Category filter

Task 4 – Advanced Analytics & Statistical Modeling

Key techniques:

- Descriptive statistics

- Correlation analysis
- Time-series analysis

Key Results

- Dataset size: 150,000 records
- Original columns: 14
- Final columns after feature engineering: 17
- Missing values: 0
- Duplicate records: 0
- Potential IQR outliers in net sales: 530
- Correlation between quantity and net sales: 0.663
- K-Means clustering was performed using three clusters.
